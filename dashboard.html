Implemented security controls

Private Session MemoryValidated session IDs partition memory and prevent cross-session retrieval.
Least-Privilege IAMAssistant can access one memory table and one configured Bedrock model.
Secrets BoundaryThe API token value stays out of source code and Terraform state.
Tool Allow-listThe model cannot invent or authorize additional tools.
Approval GateDestructive, privileged, credential, and production-changing requests are stopped before execution.
Hardened Local RuntimeNon-root container, dropped Linux capabilities, loopback publishing, and persistent SQLite volume.
Higher-risk requests do not execute automatically.The assistant returns an approval-required response and escalation guidance instead of treating model output as permission.
